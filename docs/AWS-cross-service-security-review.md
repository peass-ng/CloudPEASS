# AWS cross-service security review tracker

This inventory covers trust paths that a service-only inventory misses. It records the technique, prerequisites, and final outcome without retaining lab identities, fixtures, proof artifacts, dates, regions, or teardown narratives.

Status values are `queued`, `in_progress`, `validated`, `negative`, `blocked`, and `conditional`. `Negative` means the tested generic claim did not work; it does not mean every application-specific composition is safe.
